초기 설정

Firebase 프로젝트를 연결하고 앨범을 설정하세요.

Firebase 프로젝트 만드는 법:
1. Firebase Console 접속 후 프로젝트 추가
2. 프로젝트 설정 > 웹 앱 추가 > firebaseConfig 복사
3. 좌측 메뉴 > Storage 활성화 > 규칙을 allow read, write: if true;로 변경
4. 좌측 메뉴 > Firestore Database 활성화 > 규칙을 allow read, write: if true;로 변경
